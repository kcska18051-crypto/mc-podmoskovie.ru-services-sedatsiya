# Центр имплантации — локальный макет

Открыть `dist/index.html` в браузере либо запустить `start-preview.ps1` и перейти на http://127.0.0.1:8771/.

Готовая страница: `dist/index.html`, стили `dist/design.css`, поведение `dist/app.js`. Все изображения и шрифты локальные, в `dist/assets`.

Формы демонстрационные: проверяют поля и открывают сообщение, данные никуда не отправляются. Перед публикацией подключить обработчик и документы о персональных данных. Цены, показатели, отзывы и сведения о врачах взяты из предоставленного прототипа и требуют финального согласования клиникой. Объёмные иллюстрации созданы для визуальной концепции, не изображают конкретную марку имплантата. Блок врачей оставлен для отдельного обсуждения.

Сборка не требует зависимостей. `build.py` извлекает содержание и ресурсы из соседнего `implant-reference.html`, добавляет логотип и иллюстрации из `../artwork`. Для передачи или GitHub достаточно содержимого `dist`; публикация пока не выполнялась.
