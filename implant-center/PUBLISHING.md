# Публикация согласованного макета

- Репозиторий: https://github.com/kcska18051-crypto/podmoskovie-implant-center
- Просмотр: https://kcska18051-crypto.github.io/podmoskovie-implant-center/
- Публикация GitHub Pages: ветка `main`, корень репозитория.
- Отдельная рабочая копия публикации: `github-preview/`.
- Исходный локальный макет: `dist/`; сборка через `build.py` и `revision.py`.

Открытая публикация подтверждена пользователем. Формы остаются демонстрационными. Перед последующими обновлениями переносить актуальные файлы из `dist/` в `github-preview/`, проверять изменения и публиковать из отдельной рабочей копии. Родительский репозиторий страницы седации не используется для этого лендинга.

## Единый источник CSS

Редактировать только `implant-center/styles.css`. `build.py` копирует его в `dist/styles.css`; старые CSS не участвуют в сборке. `consolidate_styles.py` оставлен как совместимый вызов копирования, а не склейки.

Перед публикацией выполнить `check-page.py` и `node audit-duplicates.cjs`. Инструкция для переноса опубликована в `github-preview/STYLES.md`. Однократные скрипты очистки и прежние версии находятся в `audit/css-cleanup`; не использовать их для повседневной сборки.
