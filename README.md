# Наркоз/Седация — Центр стоматологии «Подмосковье»

Исходный HTML страницы <https://www.mc-podmoskovie.ru/services/sedatsiya/>, перенесённый без самостоятельной перерисовки разметки, таблицы или компонентов.

В `index.html` сохранены оригинальные классы, тексты, формы и JavaScript-интеграции Bitrix. Тег `base` направляет исходные корневые пути к стилям, скриптам, изображениям и шрифтам на сайт клиента, поэтому страница отображается так же, как оригинал.

## Локальный просмотр

Запустите любой статический HTTP-сервер из корня проекта, например:

```text
python -m http.server 4173
```

Затем откройте <http://127.0.0.1:4173/>.

## Проверка

```text
npm test
```

Формы и их исходная разметка не изменялись.
