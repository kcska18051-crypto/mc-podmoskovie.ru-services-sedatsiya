# Наркоз/Седация — Центр стоматологии «Подмосковье»

Автономная статическая копия страницы <https://www.mc-podmoskovie.ru/services/sedatsiya/> для согласования и последующей переработки блока сравнения, цен и контента.

## Локальный просмотр

Запустите любой статический HTTP-сервер из корня проекта, например:

```text
python -m http.server 4173
```

Затем откройте <http://127.0.0.1:4173/>.

## Проверка

```text
npm test
```

Формы сохранены как часть внешнего вида страницы. Отправка данных намеренно отключена.
