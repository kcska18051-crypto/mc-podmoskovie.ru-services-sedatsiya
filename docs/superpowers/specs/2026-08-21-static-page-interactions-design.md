# Исправление интерактивности статической страницы «Седация/наркоз»

## Цель

Сделать сохранённую на GitHub Pages версию функциональной без подключения исходного Bitrix JavaScript и без изменения согласованного дизайна таблицы и FAQ.

## Поведение

- Вкладки врачей переключают соответствующую карточку; активна ровно одна вкладка.
- Стрелки отзывов последовательно показывают один из трёх отзывов и обновляют счётчик.
- Форма проходит встроенную HTML-проверку, не отправляет персональные данные через GitHub и переводит пользователя в Telegram клиники. Рядом с кнопкой явно указано, что данные демо-страницей не передаются.
- Кнопка сравнительной таблицы после повторного закрытия показывает правильное значение «ещё 3 раздела».
- Пустой раздел «Видео» скрыт до появления роликов.
- Заголовки вопросов FAQ используют локально подключённый `SiteUbuntu`.
- Исправлена опечатка «я Ярославле» в заголовке вкладки браузера.

## Доступность

- Вкладкам врачей назначаются роли `tablist`, `tab`, `tabpanel`, а также `aria-selected` и `aria-controls`.
- Неактивные карточки врачей получают `hidden`.
- Кнопки отзывов сохраняют нативное управление с клавиатуры; крайние кнопки получают корректное состояние `disabled`.

## Проверка

- Статические тесты проверяют наличие обработчиков, корректный счётчик, скрытие видео и безопасный режим формы.
- Браузерный тест выполняется на ширинах 1440 и 390 пикселей и проверяет каждое переключение.
