# Локальные доработки — UI-кит

12 задач для согласования изменений сайта «Подмосковье». Все HTML, стили, иллюстрации и комментарии для клиники сохранены в этой папке.

## Просмотр

Из корня проекта: `node local-ui-kit/server.cjs`, затем открыть http://127.0.0.1:8766/.

Основной файл: `index.html`. Отдельные макеты доступны по ссылкам «Открыть отдельно» в каждой задаче. Медицинские тексты, цены, состав комплексов, показатели и условия гарантии требуют согласования, указанного в комментариях. Формы демонстрационные, данные не отправляют.

Для маршрута `/nobel/` нужен соседний checkout `podmoskovie-nobel-zygoma` из https://github.com/kcska18051-crypto/podmoskovie-nobel-zygoma (ветка `client-review`). Он хранится отдельным Git-репозиторием и не является подмодулем основного проекта.

## Состав задач

1. Статус авторизованного центра Nobel.
2. Стоимость лечения Nobel.
3. FAQ Nobel.
4. Баннеры статуса и гарантий, отдельный блок гарантии.
5. Комплексы и отдельные цены общей имплантации.
6. Главный баннер и показатели опыта.
7. Консультация: цена, длительность, состав.
8. Плашки услуг и поясняющие окна.
9. Баннер налогового вычета.
10. Дополнение FAQ общей имплантации.
11. Карусель технологий: Planmeca, внутриротовой сканер, хирургические шаблоны.
12. Отдельный вопрос о статусе центра, показанный в общем FAQ.

## Ресурсы

Изображения включают материалы сайта клиники, созданные для макетов иллюстрации и выбранный референс хирургического шаблона ROE Dental Laboratory. Источники и требуемые подтверждения отмечены в задачах. Публикация на сайт клиники этим сохранением в GitHub не выполняется.

Готовые HTML уже сохранены. Скрипты `build-*.cjs` и вспомогательные скрипты отражают этапы подготовки; некоторые используют локальные снимки источников и не предназначены для запуска одной общей командой сборки. Текущий `index.html` — актуальный перечень согласуемых задач.
